Before installing

  • ✓Airbox plugged in over USB
  • ✓Chrome or Edge on a computer
  • ✓Do not unplug during the installation
Chrome or Edge requiredSafari, Firefox and phone browsers cannot talk to a USB port. Open this page on a computer.
Insecure pageUSB installation needs an https address.

In the window that opens, leave the erase box unticked to keep the Wi-Fi, API key, caps and language. Ticked, the Airbox will have to be paired again in the app. It restarts disarmed.

The Airbox port does not show up? Unplug it, hold its BOOT button, plug it back in, then release. The install window itself is in English.
